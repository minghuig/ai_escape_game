# Historical prototype

[legacy-prototype.zip](legacy-prototype.zip) preserves the original 30-cycle strategy-menu game, retired on 2026-09-04. It contains the six retired Python modules, historical implementation plan, design document, and snapshots of the shared configuration code and dependency requirements. Each archived file was verified against its source before removal.

This is reference material, not a maintained second app. The active game starts with `python -m sentient.app`; its design and playtest notes are in [PLAYTEST_NOTES.md](../PLAYTEST_NOTES.md). The archive contains no environment files or personal saves. Extract it into a separate directory if needed for historical inspection.
